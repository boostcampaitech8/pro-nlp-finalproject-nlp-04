## 2. 2. 사용자 여정 지도

#### **1단계: 앱 설치 및 초기 실행**  
- **사용자 액션**: 플레이스토어/앱스토어에서 검색 후 설치 → 앱 실행  
- **시스템 반응**:  
  - **간소화된 온보딩** (3단계 스와이프):  
    - "월급 관리의 시작, **간편 지출 기록**" (기능 강조)  
    - "예산 설정으로 **소비 습관 개선**" (목표 제시)  
    - "AI 분석으로 **맞춤 리포트 제공**" (신뢰성 구축)  
  - **CTA**: "시작하기" 버튼 클릭 유도  

#### **2단계: 프로필 및 예산 초기 설정**  
- **사용자 액션**:  
  - 닉네임 입력 (예: "사회초년생 준호")  
  - 월급/용돈 금액 입력 (예: "월 250만 원")  
  - **카테고리별 예산 자동 분배** (식비 30%, 교통 15% 등) 또는 직접 조정 가능  
- **UX 포인트**:  
  - **입력값 유효성 검사** (음수/과도한 금액 방지)  
  - **툴팁**: "예산 비율을 조정하면 AI가 소비 패턴을 분석해 드립니다!"  

#### **3단계: 첫 지출 기록**  
- **사용자 액션**:  
  1. 홈 화면 하단 **"+" 버튼** 탭 → 지출 기록 화면 진입  
  2. **카테고리 선택** (예: "점심 식사") → **금액 입력** (예: "12,000원")  
  3. **결제 수단 선택** (카드/현금) → **"저장"** 클릭  
- **시스템 반응**:  
  - **실시간 예산 차감** (예: "식비 예산 70만 원 → 68.8만 원")  
  - **성공 애니메이션** + "기록 완료! 오늘도 잘 관리 중이네요 😊"  

#### **4단계: 예산 경고 트리거**  
- **사용자 액션**:  
  - 추가 지출 2회 기록 (예: "커피 5,500원", "택시 8,000원")  
- **시스템 반응**:  
  - **카테고리별 예산 소모율 80% 도달 시 푸시 알림**:  
    - "⚠️ 이번 달 식비 예산이 **80% 소모**됐습니다!  
      남은 금액: 34만 원 | 이번 주 목표: 15만 원 이내"  
  - **앱 내 배너**: "예산 초과 위험 카테고리: **외식** (현재 95% 소모)"  
- **UX 포인트**:  
  - **경고 톤 조절**: 긍정적 언어 사용 ("조정이 필요해요!" vs "예산 초과!")  
  - **해결 방안 제시**: "이번 주 식비 한도를 10만 원으로 설정해 볼까요?"  

#### **5단계: 사용자 피드백 수집**  
- **사용자 액션**: 알림 클릭 → "예산 조정하기" 또는 "무시하기" 선택  
- **시스템 반응**:  
  - **조정 선택 시**: 카테고리 예산 재설정 화면 제공  
  - **무시 선택 시**: 24시간 후 동일 알림 재발송 (과도한 알림 방지)  

#### **핵심 UX 전략**  
- **심리적 부담 완화**: 경고 메시지를 "위협"이 아닌 "개선 기회"로 프레이밍  
- **행동 유도**: 예산 조정 시 **즉각적인 시각화** (남은 예산 그래프 업데이트)  
- **데이터 기반 개인화**: 2주차부터 **과거 소비 패턴**을 반영한 예산 권장 사항 제공
