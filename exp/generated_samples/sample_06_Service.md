## 2. 2. 비대면 진료 프로세스

**환자 중심의 직관적 UX 설계로 진료 접근성 및 효율성 극대화**  

#### 1. **증상 입력 단계**  
- **간편한 증상 선택 UI**  
  : 자주 발생하는 증상 카테고리(감기, 두통, 소화불량 등)를 아이콘/키워드 기반으로 시각화, 드래그 앤 드롭으로 복수 증상 선택 가능  
  : 음성 입력 또는 사진 첨부로 증상 상세 설명 지원 (예: 피부 발진 사진 업로드)  
- **AI 기반 증상 분석**  
  : 입력 증상 기반으로 진료과 추천 및 응급도 판단 (예: "39°C 이상 발열 시 응급실 연계 권장")  
  : 과거 진료 기록 연동으로 환자 이력 자동 추출  

- **실시간 의사 현황 표시**  
  : 진료 가능 의사 프로필(경력, 전문분야, 평점) 및 예상 대기 시간 제공  
  : 긴급도 선택 시 우선 연결 기능 (예: "응급" 체크 시 대기 시간 50% 단축*)  
- **자동 연결 옵션**  
  : 환자가 예약 없이 즉시 화상 진료로 전환 가능하도록 설계, 대기 중 증상 추가 입력 창 제공  

#### 3. **문진표 작성**  
- **필수 항목 자동 완성**  
  : 기저질환, 복용 중인 약물, 알레르기 정보는 이전 진료 기록에서 자동 추출  
  : 증상 기간/강도 슬라이더 바로 입력 (예: "지난 3일간 7/10 통증")  
- **맞춤형 질문 생성**  
  : 증상 기반으로 의사에게 필요한 추가 질문 자동 생성 (예: "복통 위치에 따라 사진 촬영 요청")  

#### 4. **화상 진료 연결**  
- **원클릭 접속 기능**  
  : 진료 시작 1분 전 푸시 알림 발송, 테스트 영상/음성 체크 기능 내장  
  : 의사가 환자 증상 요약본 미리 확인 가능하도록 동기화  
- **실시간 상호작용 도구**  
  : 화면 공유로 진료 기록/의학 자료 동시 확인, 메모 기능으로 의사-환자 간 즉각적 소통 지원  

#### 5. **진료 완료 및 후속 조치**  
- **전자처방전 즉시 발급**  
  : 진료 종료 후 3분 내 처방전 생성, 약국 연계 배송 또는 수령 확인 시스템 연동  
  : 복약 지도 영상 제공 (예: "항생제 복용법 10초 영상 재생")  
- **자동 결제 프로세스**  
  : 보험 청구 정보 자동 연동, 진료비 명세서 PDF 제공 (의료기관별 요금 체계 투명화)  

#### 6. **추적 관리 시스템**  
- **증상 추적 알림**  
  : 처방 후 24시간/48시간 차 증상 확인 설문 자동 발송  
  : 중증 환자 대상 7일 간 일일 체크인 기능 (체온, 통증 정도 기록)  
- **재진료 권장 알고리즘**  
  : 증상 개선 없을 시 의사 재연락 또는 병원 방문 권고, 지역 내 협력 병원 정보 제공  

**※ 모든 단계에서 개인정보 암호화 및 의료법 준수**  
- 진료 기록 저장 시 HIPAA/KISMEF 기준 적용  
- 의사 신원 및 자격 검증 시스템 필수 연동
