## 2. 2. 가구 배치 UX

- **공간 인식 기반 배치 프로세스**  
  - 사용자가 카메라 화면에 특정 가구 아이템을 장시간 탭(1.5초)하면 **3D 모델이 실제 공간 스케일로 자동 생성**  
  - **드래그 앤 드롭**으로 원하는 위치 이동 시, 바닥/벽면 인식 알고리즘이 작동해 물리적 경계 내에서 자연스럽게 정렬  
  - 모델 회전은 **두 손가락 스와이프**로 구현, 수직/수평 축별 15° 단위 고정 각도 제공으로 미세 조정 지원  

- **실시간 조작 피드백 시스템**  
  - 이동/회전 시 **50ms 이내 비주얼 리액션**으로 조작감 개선 (예: 반투명 그림자 생성, 축 정렬 가이드 라인)  
  - 핀치 투 줌 제스처로 **크기 조정** 가능, 최대/최소 크기 제한 설정으로 현실성 유지  
  - 배치 완료 시 **햅틱 진동**과 함께 "찰칵" 사운드로 확정 신호 전달  

- **상황 인지형 보조 기능**  
  - 가구 간 간격 자동 감지: 다른 아이템과 30cm 이내 접근 시 **경고 애니메이션** 표시  
  - 벽면/문 위치 인식: 가구 배치 시 **자동 정렬 보조선** 제공 (예: 침대 헤드보드를 벽면에 밀착)  
  - 카메라 각도 변경 시 **모델 위치 메모리 기능**으로 사용자 시점 변화에 따른 혼란 방지  

- **접근성 강화 설계**  
  - 제스처 조작에 어려움을 겪는 사용자를 위한 **대체 UI 버튼** 배치 (회전/크기 조절 패널)  
  - 음성 명령 연동: "왼쪽으로 45도 회전"과 같은 명령어 인식 후 자동 실행  
  - 저조도 환경에서의 **적외선 프로젝션 가이드**로 정확한 표면 인식 지원  

> 모든 상호작용은 **3단계 확인 프로세스**를 거치도록 설계:  
> 1) 초기 배치 → 2) 미세 조정 → 3) 공간 검증 (주변 환경과의 물리적 충돌 검토)
