## 1. 1. 매물 검수 절차

**1단계: 사용자 입력 단계**  
- 차량 등록 시 **필수 입력 항목**으로 차량 번호판, 차대번호, 성능기록부 이미지 업로드 추가  
- 번호판 입력 시 **실시간 유효성 검증** (형식/지역 코드 일치 여부) 수행  

**2단계: 번호판 조회 API 연동**  
- **국토교통부 차량등록정보 API**와 연동하여 다음 정보 확인:  
  - 차량 존재 여부 및 등록 상태 (말소/유효)  
  - 차대번호, 차종, 연식 등 기본 정보 일치성 검증  
- **API 응답 지연 시** 3회 재시도 후 수동 검수로 전환  

**3단계: 성능 기록부 OCR 검증**  
- 업로드된 성능기록부 이미지에 **OCR 기술 적용**하여 다음 데이터 추출:  
  - 차대번호, 검사 유효기간, 주행거리, 사고 이력  
- 추출된 데이터와 번호판 API 결과 **대조 분석**:  
  - 주행거리 ±5% 초과 시 경고 발생  
  - 사고 이력 불일치 시 추가 서류 요청 (예: 보험 처리 내역)  

**4단계: 자동 필터링 시스템**  
- 다음 조건 충족 시 **실매물 확정** 및 등록 승인:  
  ✓ API/OCR 데이터 90% 이상 일치  
  ✓ 주행거리 변동 폭 ±5% 이내  
- 불일치 시 **3단계 에스컬레이션**:  
  1. 딜러에게 24시간 내 추가 증빙 요청  
  2. 미제출 시 매물 보류 및 경고 점수 부여  
  3. 3회 누적 시 딜러 계정 정지  

**5단계: 수동 검수 백업**  
- AI 필터링 통과 매물 중 **랜덤 5% 샘플링**하여 전문 검수팀 수동 확인  
- 고위험 매물 (고가/수입차)은 **100% 수동 검증** 절차 적용  

**프로세스 효과**  
- 허위 매물 1차 차단률 **92% 이상** (시뮬레이션 기준)  
- OCR 오류율을 3% 미만으로 유지하기 위한 **이미지 품질 가이드** 병행 제공  
- 모든 검수 이력 **블록체인 기반 로그**에 저장하여 투명성 확보
