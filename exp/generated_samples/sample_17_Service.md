## 2. 2. 위기 상황 감지

- **실시간 키워드 감지 시스템**  
  - 자연어 처리(NLP) 기반 감정 분석 모델을 활용해 대화 중 **자해·자살 관련 암시 단어** (예: "죽고 싶어", "끝내고 싶다")를 즉시 식별  
  - 다단계 필터링 적용:  
    1차: 사전 정의된 위험 단어 목록 매칭 → 2차: 문맥 분석을 통한 위험 수준 평가 → 3차: 사용자 이력(예: 반복적 위기 표현) 종합 판단  

- **위험 감지 시 즉각적 대응 절차**  
  - **긴급 도움 버튼** 활성화: 화면 상단에 빨간색 경고 배너 + "지금 바로 도움을 받으실 수 있습니다" 팝업 표시  
  - **3단계 안전 확인 프로세스**:  
    1. "현재 마음 상태가 많이 힘드시겠어요. 잠시 이야기해 볼까요?"라는 공감 메시지 전달  
    2. 30초 내 응답 없을 시 자동 재알림  
    3. 명시적 거부 의사 표현 시 "언제든 다시 연락 주세요"라는 배려 메시지 전송  

- **윤리적 고려 사항**  
  - **거짓 양성 최소화**: 상황별 문맥 가중치 부여 (예: "시험 망쳐서 죽고 싶다" vs "영화 장면이 죽을 만큼 슬펐다")  
  - **개인정보 보호**: 상담원 연결 전 반드시 사용자 동의 획득 → 익명 상담 옵션 제공  
  - **사후 모니터링**: 위기 감지 후 72시간 동안 추가 이상 신호 감지 시 보호자/긴급기관 연계 프로토콜 자동 실행  

- **시스템 검증 프로세스**  
  - 주간 위기 키워드 오탐률 분석 리포트 생성 → NLP 모델 재학습 주기 설정  
  - 상담원과의 연계를 통한 실제 사례 기반 위험 단어 사전 지속 업데이트
